# 本地中间件环境（开发用）

> 换机器/重启后照这份文档恢复。**密码不写在这里**（都在 `application-local.yml`）。

## 三、RocketMQ 5.3.1（Docker）

| 项 | 值 |
|---|---|
| 镜像 | `apache/rocketmq:5.3.1` |
| NameServer | `127.0.0.1:9876`（容器 `rmqnamesrv`，端口映射）|
| Broker（宣告）| `10.120.10.204:10911`（容器 `rmqbroker`）|
| 网络 | 自定义 `rmq-net`（bridge）|
| 客户端配置 | `rocketmq.name-server: 127.0.0.1:9876` |

### ⚠️ 关键：为什么 Broker 要宣告 `10.120.10.204`（宿主机 IP）

```
Docker Desktop（Windows）的容器在 WSL2 虚拟网络里，容器 IP（172.x）宿主机不可达
→ Broker 默认把自己的容器 IP 注册到 NameServer
→ 宿主机 Java 客户端拿到 172.x:10911 → 连不上（ConnectionRefused/Timeout）
→ 解决：brokerIP1 = 宿主机可达 IP（WLAN 192.168.x / 10.x）
```

> 换 WiFi/网络后宿主机 IP 可能变 → **改 brokerIP1 并重启 Broker**（见下）。

### 启动命令（首次/重建容器）

```bash
# ① 网络
docker network create rmq-net

# ② NameServer
docker run -d --name rmqnamesrv --network rmq-net -p 9876:9876 \
  -e "JAVA_OPT_EXT=-Xms256m -Xmx256m -Xmn128m" \
  apache/rocketmq:5.3.1 sh mqnamesrv

# ③ Broker（brokerIP1 填【宿主机当前 IP】）
docker run -d --name rmqbroker --network rmq-net -p 10911:10911 -p 10909:10909 \
  -e "NAMESRV_ADDR=rmqnamesrv:9876" \
  -e "JAVA_OPT_EXT=-Xms512m -Xmx512m -Xmn256m" \
  apache/rocketmq:5.3.1 \
  sh -c 'sed -i "/^brokerIP1/d" /home/rocketmq/rocketmq-5.3.1/conf/broker.conf; \
         echo "brokerIP1=<宿主机IP>" >> /home/rocketmq/rocketmq-5.3.1/conf/broker.conf; \
         sh /home/rocketmq/rocketmq-5.3.1/bin/mqbroker -n rmqnamesrv:9876 -c /home/rocketmq/rocketmq-5.3.1/conf/broker.conf'
```

### 日常重启（容器已存在）

```bash
docker start rmqnamesrv rmqbroker
```

### 验证

```bash
# 集群状态（Addr 应为宿主机 IP）
docker exec rmqbroker sh -c 'sh /home/rocketmq/rocketmq-5.3.1/bin/mqadmin clusterList -n rmqnamesrv:9876'

# 发一条测试消息
docker exec rmqbroker sh -c 'sh /home/rocketmq/rocketmq-5.3.1/bin/mqadmin sendMessage -n 127.0.0.1:9876 -t cloudticket-test -p "hello"'
# → SEND_OK 即正常
```

### 踩过的坑

| 坑 | 现象 | 解决 |
|---|---|---|
| 挂载 broker.conf（`-v` Git Bash 路径）| Broker 启动报 `loadConfig` 失败 | 改为容器内 `sed/echo` 改 conf |
| `mqbroker -n` 不读 broker.conf | brokerIP1 不生效（仍是容器 IP）| 显式加 `-c /home/rocketmq/.../conf/broker.conf` |
| `--network host`（Docker Desktop Windows）| 宿主机连不上（host 是虚拟化的）| 别用 host，用 bridge + 端口映射 + 宿主机 IP 宣告 |
| Broker 内存默认 8G | 容器 OOM/起不来 | `-e JAVA_OPT_EXT=-Xms512m -Xmx512m -Xmn256m` |
