# 云票接口文档 · 05 票夹模块（用户端）

> 前缀 `/user/tickets`，需用户鉴权。

## 1. 我的票分页

### 1.1 基本信息

> 请求路径：/user/tickets/page
>
> 请求方式：GET
>
> 接口描述：当前用户的票列表（票夹页），联演出/场次/票档信息

### 1.2 请求参数

参数格式：queryString

参数说明：

| 参数名   | 类型（Java / JSON）   | 是否必须 | 备注                        |
| -------- | ------ | -------- | --------------------------- |
| pageNum  | Integer（number） | 非必须   | 默认 1                      |
| pageSize | Integer（number） | 非必须   | 默认 10                     |
| status   | Integer（number） | 非必须   | 1 有效 2 已核销 3 已退款    |

请求参数样例：

```shell
/user/tickets/page?status=1&pageNum=1&pageSize=10
```

### 1.3 响应数据

参数格式：application/json

参数说明：

| 参数名          | 类型（Java / JSON）      | 是否必须 | 备注                        |
| --------------- | --------- | -------- | --------------------------- |
| code            | Integer（number） | 必须     | 1 成功，0 失败              |
| msg             | String（string） | 非必须   | 提示信息                    |
| data            | PageResult<UserTicketPageVO>（object） | 必须     | 分页数据                    |
| \|- total       | Integer（number） | 必须     | 总记录数                    |
| \|- rows        | List<UserTicketPageVO>（object[]） | 必须     | 数据列表                    |
| \|- ticketId    | Long（string） | 非必须   | 票 id                       |
| \|- ticketNo    | String（string） | 非必须   | 票号（内部唯一标识，展示用）|
| \|- ticketCode  | String（string） | 必须     | **票码凭证串（P1 静态签名）**：`ticketNo + "." + HMAC-SHA256(ticketNo, 密钥)`，前端直接渲染二维码 |
| \|- showTitle   | String（string） | 非必须   | 演出标题                    |
| \|- sessionName | String（string） | 非必须   | 场次名                      |
| \|- sessionTime | LocalDateTime（string） | 非必须   | 演出时间                    |
| \|- categoryName| String（string） | 非必须   | 票档名                      |
| \|- price       | BigDecimal（number） | 非必须   | 票价                        |

### 1.4 备注说明

- 强制 `WHERE user_id=当前用户`，`ORDER BY id DESC`；
- **票码（P1 静态签名）**：`ticketCode = ticketNo + "." + HMAC-SHA256(ticketNo, 密钥)`，由服务端签发（查询时现算，不落库；票号被篡改则验签失败）；前端把 `ticketCode` 直接渲染成二维码，核销时先验签再 CAS（见 06 §9）；
- **P4 升级（动态码）**：`GET /user/tickets/{id}/qrcode-token` —— 票号 + 时间戳 + 签名，30 秒有效期防截图转用，配合摄像头扫码；本列表接口契约不变（`ticketCode` 换成动态串）；
- 演出结束 7 天后未核销的票自动置"已作废"（定时任务，P4 一起做）。
