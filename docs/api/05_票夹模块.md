# 云票接口文档 · 05 票夹模块（用户端）

> 前缀 `/user/tickets`，需用户鉴权。

## 1. 我的票分页

### 1.1 基本信息

> 请求路径：/user/tickets/page
>
> 请求方式：GET
>
> 接口描述：当前用户的票列表（票夹页），联演出/场次/票档信息

### 1.2 请求参数

参数格式：queryString

参数说明：

| 参数名   | 类型   | 是否必须 | 备注                        |
| -------- | ------ | -------- | --------------------------- |
| pageNum  | number | 非必须   | 默认 1                      |
| pageSize | number | 非必须   | 默认 10                     |
| status   | number | 非必须   | 1 有效 2 已核销 3 已退款    |

请求参数样例：

```shell
/user/tickets/page?status=1&pageNum=1&pageSize=10
```

### 1.3 响应数据

参数格式：application/json

参数说明：

| 参数名          | 类型      | 是否必须 | 备注                        |
| --------------- | --------- | -------- | --------------------------- |
| code            | number    | 必须     | 1 成功，0 失败              |
| msg             | string    | 非必须   | 提示信息                    |
| data            | object    | 必须     | 分页数据                    |
| \|- total       | number    | 必须     | 总记录数                    |
| \|- rows        | object [] | 必须     | 数据列表                    |
| \|- ticketId    | string    | 非必须   | 票 id                       |
| \|- ticketNo    | string    | 非必须   | 票号（动态二维码数据源）    |
| \|- showTitle   | string    | 非必须   | 演出标题                    |
| \|- sessionName | string    | 非必须   | 场次名                      |
| \|- sessionTime | string    | 非必须   | 演出时间                    |
| \|- categoryName| string    | 非必须   | 票档名                      |
| \|- price       | number    | 非必须   | 票价                        |
| \|- status / statusDesc |   | 非必须   | 有效/已核销/已退款          |
| \|- checkTime   | string    | 非必须   | 核销时间（未核销为 null）   |

响应数据样例：

```json
{
  "code": 1,
  "msg": "success",
  "data": {
    "total": 3,
    "rows": [
      {
        "ticketId": "9001",
        "ticketNo": "TK202610022235000001",
        "showTitle": "星野巡回演唱会·广州站",
        "sessionName": "周六晚场",
        "sessionTime": "2026-11-21 19:30:00",
        "categoryName": "内场VIP",
        "price": 1280.00,
        "status": 1,
        "statusDesc": "有效",
        "checkTime": null
      }
    ]
  }
}
```

### 1.4 备注说明

- 强制 `WHERE user_id=当前用户`，`ORDER BY id DESC`；
- **票号动态码**：P4 实现签名接口 `GET /user/tickets/{id}/qrcode-token`（HMAC 签名 + 30 秒有效期，前端定时刷新渲染二维码）——P1 票夹先展示明文票号占位；
- 演出结束 7 天后未核销的票自动置"已作废"（定时任务，P4 一起做）。
