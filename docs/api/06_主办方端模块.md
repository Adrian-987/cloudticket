# 云票接口文档 · 06 主办方端模块

> 前缀 `/merchant/**`，需主办方鉴权（密钥 B）。
> **数据权限贯穿**：所有列表/详情接口强制 `merchant_id=当前登录主办方`（@DataScope 落点），改 id 越权访问返回"数据不存在"。

## 1. 创建演出（含场次票档）

### 1.1 基本信息

> 请求路径：/merchant/shows
>
> 请求方式：POST
>
> 接口描述：创建演出（草稿态），一次提交含场次与票档（库存）定义

### 1.2 请求参数

参数格式：application/json

参数说明：

| 参数名                       | 类型      | 是否必须 | 备注                              |
| ---------------------------- | --------- | -------- | --------------------------------- |
| title                        | string    | 必须     | 2~128 字                          |
| category                     | string    | 必须     | 分类常量之一                      |
| venueId                      | string    | 必须     | 场馆 id                           |
| coverUrl                     | string    | 非必须   | 封面（OSS 上传接口返回的地址）    |
| detail                       | string    | 非必须   | 图文详情（富文本）                |
| guide                        | string    | 非必须   | 观演指南                          |
| sessions                     | object [] | 必须     | 1~10 个场次                       |
| \|- sessionName              | string    | 非必须   | 场次名（周六晚场）                |
| \|- sessionTime              | string    | 必须     | 演出开始时间                      |
| \|- saleStartTime            | string    | 必须     | 开售时间（≥ 当前时间）            |
| \|- saleEndTime              | string    | 必须     | 停售时间                          |
| \|- categories               | object [] | 必须     | 1~5 个票档                        |
| \|- \|- name                 | string    | 必须     | 票档名（内场VIP）                 |
| \|- \|- price                | number    | 必须     | 票价，>0                          |
| \|- \|- stock                | number    | 必须     | 公开池库存，≥0                    |
| \|- \|- memberStock          | number    | 必须     | 会员池库存，≥0（0=无会员池）      |
| \|- \|- limitPerUser         | number    | 必须     | 单用户限购，≥1                    |

请求参数样例：

```json
{
  "title": "星野巡回演唱会·广州站",
  "category": "演唱会",
  "venueId": "101",
  "coverUrl": "https://oss.cloudticket.cn/cover/501.jpg",
  "detail": "<p>星野 2026 巡回演出广州站……</p>",
  "guide": "凭身份证原件入场；开场前 90 分钟开始检票",
  "sessions": [
    {
      "sessionName": "周六晚场",
      "sessionTime": "2026-11-21 19:30:00",
      "saleStartTime": "2026-10-10 10:00:00",
      "saleEndTime": "2026-11-21 19:00:00",
      "categories": [
        { "name": "内场VIP", "price": 1280.00, "stock": 400, "memberStock": 100, "limitPerUser": 2 },
        { "name": "看台A", "price": 380.00, "stock": 500, "memberStock": 0, "limitPerUser": 4 }
      ]
    }
  ]
}
```

### 1.3 响应数据

参数格式：application/json

参数说明：

| 参数名    | 类型   | 是否必须 | 备注             |
| --------- | ------ | -------- | ---------------- |
| code      | number | 必须     | 1 成功，0 失败   |
| msg       | string | 非必须   | 提示信息         |
| data      | object | 非必须   | 返回的数据       |
| \|- showId | string | 必须    | 演出 id（草稿态）|

响应数据样例：

```json
{
  "code": 1,
  "msg": "success",
  "data": {
    "showId": "501"
  }
}
```

### 1.4 备注说明

- 校验：saleStartTime < sessionTime；创建后两池库存之和写回 `show_info.total_stock`（冗余校验）；
- merchant_id 由服务端从登录态注入，前端不传；
- 保存为**草稿**（status=0），需提交审核才进入审核流。

> 请求路径：/merchant/shows/{id}/submit
>
> 请求方式：POST
>
> 接口描述：把草稿/驳回态的演出提交平台审核

### 5.2 请求参数

参数格式：路径参数

参数说明：

| 参数名 | 类型   | 是否必须 | 备注   |
| ------ | ------ | -------- | ------ |
| id     | string | 必须     | 演出 id |

请求参数样例：


### 5.3 响应数据

参数格式：application/json

参数说明：通用 Result，data 无

响应数据样例：


- 提交后锁定编辑，直到审核出结果。

## 9. 核销

### 9.1 基本信息

> 请求路径：/merchant/tickets/check
>
> 请求方式：POST
>
> 接口描述：主办方核销一张票（扫码/输码后调用），一票一核

### 9.2 请求参数

参数格式：application/json

参数说明：

| 参数名   | 类型   | 是否必须 | 备注                              |
| -------- | ------ | -------- | --------------------------------- |
| ticketNo | string | 必须     | 票号（扫码解出或手动输入）        |

请求参数样例：

```json
{
  "ticketNo": "TK202610022235000001"
}
```

### 9.3 响应数据

参数格式：application/json

参数说明：

| 参数名          | 类型    | 是否必须 | 备注                                |
| --------------- | ------- | -------- | ----------------------------------- |
| code            | number  | 必须     | 1 成功，0 失败                      |
| msg             | string  | 非必须   | 失败原因：已核销/已退款/不存在/非本场票 |
| data            | object  | 非必须   | 核销成功时返回票面信息              |
| \|- ticketNo    | string  | 必须     |                                     |
| \|- showTitle   | string  | 必须     |                                     |
| \|- sessionName | string  | 必须     |                                     |
| \|- categoryName | string | 必须     | 票档名                              |
| \|- attendeeName | string | 必须     | 观演人姓名（脱敏）                  |

响应数据样例：

```json
{
  "code": 1,
  "msg": "success",
  "data": {
    "ticketNo": "TK202610022235000001",
    "showTitle": "星野巡回演唱会·广州站",
    "sessionName": "周六晚场",
    "categoryName": "内场VIP",
    "attendeeName": "陈**"
  }
}
```

### 9.4 备注说明

- **核销幂等 CAS**：`UPDATE ticket SET status=已核销, check_time=now WHERE ticket_no=? AND status=有效`，rows=1 成功，rows=0 返回具体原因（已核销/已退款/不存在）——重复扫码不会二次核销；
- **防跨主办方核销**：票的 session→show→merchant 链路归属校验，别人的票核不了（数据权限的又一落点）；
- 仅演出当日允许核销（session_time 当天校验）；
- 写审计日志（CHECK_IN）；
- P4 前置"票码验签 + 30s 时间窗校验"（动态票码防截图），本接口契约不变。

> 请求方式：GET
>
> 接口描述：查询平台维护的可用场馆（创建/编辑演出时的下拉数据源），只读

### 11.2 请求参数

参数格式：queryString

参数说明：

| 参数名 | 类型   | 是否必须 | 备注         |
| ------ | ------ | -------- | ------------ |
| city   | string | 非必须   | 按城市过滤   |

请求参数样例：

```shell
/merchant/venues/list?city=广州
```

### 11.3 响应数据

参数格式：application/json

参数说明：

| 参数名    | 类型      | 是否必须 | 备注           |
| --------- | --------- | -------- | -------------- |
| code      | number    | 必须     | 1 成功，0 失败 |
| msg       | string    | 非必须   | 提示信息       |
| data      | object [] | 非必须   | 场馆列表       |
| \|- id    | string    | 必须     | 场馆 id        |
| \|- name  | string    | 必须     | 场馆名称       |
| \|- city  | string    | 必须     | 城市           |
| \|- address | string  | 必须     | 详细地址       |

响应数据样例：

```json
{
  "code": 1,
  "msg": "success",
  "data": [
    { "id": "101", "name": "星海体育馆", "city": "广州", "address": "天河区体育西路 199 号" },
    { "id": "102", "name": "白云会展中心", "city": "广州", "address": "白云区云城东路 501 号" }
  ]
}
```

### 11.4 备注说明

- 场馆由平台管理员统一维护（07 模块），主办方**只读引用**——公共资源不开放给主办方录入，防止重名脏数据；
- 不分页（场馆总量小），前端下拉直接渲染。
